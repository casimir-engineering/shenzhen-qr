## New in this version

### Create
- **The Create tab** at the top of the window makes a QR code, Data Matrix, Aztec code, PDF417, Code 128, EAN-13, UPC-A or EAN-8 as a crisp PNG, saved in Downloads unless you choose another folder. **Copy Image** puts it on the clipboard.
- **Advanced** (closed until you open it) has error correction, quiet zone, Data Matrix shape, bar height, the digits under EAN and UPC barcodes, colors, a transparent background and the file name. Each starts at the standard value.

### Scanning
- **Photo** freezes the picture and reads its text, Chinese included. Select text right on the photo, or edit it in the field. Codes on the photo are outlined; click one to use it.
- **Blurred barcodes:** when the bars can't be read, the number is read from the digits printed under them, and kept only if the check digit is right.
- **Zoom:** double-click the picture to zoom 2.5× into the middle, where smaller codes are read; a zoom bar sits at the bottom of the picture.
- **Picture size:** the menu beside the camera lists the sizes that camera really has.
- **Where the code is:** a green outline marks each code; with several in view, click one to use it.
- **Copy** only copies when you click it.

### Command line
- `shenzhenqr` reads codes in pictures or from a camera, reads text (`ocr`), takes photos, makes codes (`make`) and updates the app (`update`). `shenzhenqr help` lists everything.

## Updating

From this version on, ShenzhenQR updates itself: it checks once a day, or when you choose **Check for Updates…** in the app menu. If you have an earlier version, download this one once with the button on the project page.
