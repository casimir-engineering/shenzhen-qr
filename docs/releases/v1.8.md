## New in this version

### Photos and pictures
- **Save** (⌘S, or **File › Save Photo…**) saves the photo you took, or the picture you pasted, dropped or opened. You choose where it goes and whether it is a PNG or a JPEG.
- **Copy** (⌘C) copies the photo or picture when no text is selected. With text selected, in the field or on the photo, ⌘C copies that text as before.

### Create
- **⌘C copies the code** when no text is selected, as **Copy Image** does.
- **⌘S** still saves the code in the folder shown; it is now also in the menu as **File › Save Code**.
